# Governance

The Psilocybin Research Tracker is currently maintained by Christopher B. Germann. The maintainer is responsible for scientific scope, source and rights boundaries, releases, security response, and production deployment.

Routine changes are discussed through issues and reviewed through pull requests. Decisions prioritize factual accuracy, reproducibility, rights-safe public data, accessibility, maintainability, and researcher value. Substantial changes to dataset scope, licensing, public redistribution, or security architecture require explicit maintainer review.

Additional maintainers may be appointed after sustained, trusted contributions. Repository access is granted according to the minimum permissions needed for the role.

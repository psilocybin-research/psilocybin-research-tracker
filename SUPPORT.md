# Support

## Using the Tracker

Start with the [project documentation](docs/getting-started.md) and the public [About page](https://psilocybin-research.com/about.php). The tracker is a research and reference resource; it does not provide medical, treatment, or legal advice.

## Where to Ask

- Reproducible software problem: open a bug report.
- Missing, duplicate, or incorrect record: use the data/source coverage issue form and include a DOI, PubMed ID, registry ID, title, or authoritative source link.
- Proposed capability: open a feature request and describe the research workflow.
- Security or private-data concern: email `info@psilocybin-research.com`; do not open a public issue.

Support is maintainer-led and provided on a best-effort basis. Requests containing credentials, private databases, subscription data, or unpublished source payloads will be closed or moved to a private channel.
